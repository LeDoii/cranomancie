# CRANOMANCIE 2000

Lecture du crâne chauve selon Oswald Bald, en ligne : <https://ledoii.github.io/cranomancie/>

Petit outil de jeu de rôle pour **Elixir RP**. Tout le contenu (guide d'Oswald Bald, signes, définitions, phrases) est de l'**invention**. Projet de joueur, sans lien officiel avec le serveur.

## Utilisation

- **Trois axes** : Lignes (le chemin), Imperfections (les marques), Forme (la nature). Chacun donne un signe parmi vingt, avec deux définitions : favorable ou défavorable.
- **Lecture** : saisissez un nombre de 1 à 20 par axe (flèches, molette, 🎲), puis lancez la polarité de chaque axe (pair = favorable, impair = défavorable). La conclusion compte les signes favorables.
- **Copier** : chaque ligne de la conclusion se copie pour le chat. Le format `/me` (activé par défaut) écrit la phrase à la troisième personne : le jeu ajoute lui-même « l'individu ».
- **Carte** : « 📇 Exporter la carte » produit une carte de lecture au nom de la personne, en PNG ou PDF, avec la date du calendrier du serveur. Elle peut aussi se copier dans le presse-papiers ou obtenir un lien direct.
- **Bibliothèque des signes** : les 60 signes, avec recherche et navigation au clavier. Les signes sont modifiables ; les modifications restent dans votre navigateur.
- **Réglages** : format `/me`, polarité manuelle, salle animée, musique de fond (coupée par défaut).
- **Interface masquée** : « 👁 Masquer l'interface » (ou touche `H`) ne laisse que la salle ; la molette zoome, glisser déplace.
