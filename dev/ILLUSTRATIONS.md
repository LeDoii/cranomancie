# Cranomancie — illustrations des 22 cartes : ce qu'il faut fournir (brouillon v1)

Principe : une carte = un élément du lore déjà cité dans `ARCANES_v1.md`. Ordre de priorité : (1) image existante dans `Data/`, (2) image fournie par l'utilisateur (capture en jeu, image du wiki), (3) ComfyUI en dernier recours, avec une carte validée comme référence de style. Le numéro et le nom restent dessinés par script.

Sources : **HM** = Histoire de la magie 1ère année ; **GR** = Guide de Rivenguard ; **CM** = Créatures magiques 1ère année. Seules 8 pages de ces livres ont été regardées pour cette liste : il peut y avoir d'autres images utilisables.

## Points à confirmer

- Emblèmes : **confirmés** par les fichiers du wiki (`/fr/lore`, dossier `emblems/`, téléchargés le 2026-10-03 sur demande de l'utilisateur) : Azuralys = phénix bleu, Felora = chat noir, Ferrox = tigre blanc, Oragonn = dragon doré, plus le blason Wendelhart. Utilisés sur les cartes III, IV, V, VIII et X (les quatre maisons sur La Roue de Fortune, choix de l'utilisateur) (aperçu : `emblems/apercu_cartes_v1.png`). Ces images appartiennent au serveur : elles ne sont **pas** dans le dépôt GitHub public tant que le staff n'a pas donné son accord (l'application retombe sur le sceau géométrique).
- Faut-il des illustrations pour toutes les cartes ou seulement pour certaines ? Les cartes sans image gardent le sceau géométrique actuel.
